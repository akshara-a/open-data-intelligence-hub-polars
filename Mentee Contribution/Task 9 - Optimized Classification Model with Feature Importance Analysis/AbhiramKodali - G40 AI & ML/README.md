# Task 9 – Optimized Classification Model with Feature Importance Analysis

## Objective

Build an optimized machine learning classification model to predict customer purchase likelihood using e-commerce customer behavior data.

## Dataset

Synthetic E-commerce Customer Dataset

## Models Implemented

- Logistic Regression
- Decision Tree
- Random Forest
- Optimized Logistic Regression (GridSearchCV)

## Techniques Used

- Exploratory Data Analysis (EDA)
- Data Cleaning
- Feature Engineering
- Pipeline Preprocessing
- Hyperparameter Tuning
- Feature Importance Analysis
- ROC-AUC Evaluation
- Model Persistence using Joblib

## Project Structure

```
data/
models/
notebooks/
reports/
src/
README.md
requirements.txt
```

## Results

The optimized Logistic Regression model achieved the best overall performance based on ROC-AUC and was selected as the final model.

## Business Insights

- Identify customers with high purchase probability.
- Improve personalized marketing campaigns.
- Optimize promotional targeting.
- Increase customer conversion rates.
