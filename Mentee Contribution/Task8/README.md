# Task 8 - Customer Segmentation with Actionable Business Insights

## Objective
The objective of this project is to segment customers into different groups using K-Means Clustering based on their purchasing behavior and provide actionable business insights for targeted marketing.

## Dataset
Mall Customers Dataset

Features:
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Algorithm Used
- K-Means Clustering

## Evaluation Metrics
- Inertia
- Silhouette Score

## Libraries Used
- pandas
- numpy
- matplotlib
- scikit-learn

## Business Insights
The clustered customer segments help businesses:
- Identify high-value customers.
- Design personalized marketing campaigns.
- Improve customer retention.
- Optimize promotional offers.

## How to Run
1. Install the required libraries.
2. Open `Task8_Customer_Segmentation.ipynb`.
3. Run all cells.
