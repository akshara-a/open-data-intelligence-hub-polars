# Mini Project 5 — Optimized Classification Model with Feature Importance Analysis

## Contents
```
MiniProject5_Purchase_Prediction.ipynb   Main notebook (EDA -> prep -> 3 baseline models -> tuning -> feature importance -> threshold -> business insights)
generate_dataset.py                       Offline fallback data generator (same schema as the real Kaggle/UCI dataset)
data/online_shoppers_intention.csv        Dataset used for this run
Decision_Log.md                           Dataset choice, feature mapping, modeling assumptions
Model_Comparison_Report.md                Full mentor-validated report (all required sections)
Feature_Importance_Report.md              Top 10 features, direction, business interpretation, action
Business_Recommendations.md               6 recommendations, each with finding / interpretation / action / benefit / risk
Mentor_Evaluation_Checklist.md             Requirement-by-requirement checklist
outputs/                                   All charts, comparison table, feature importance, threshold analysis (generated by the notebook)
models/                                    Saved final pipeline (.pkl) — preprocessing + classifier together
```

## Dataset
**Kaggle:** https://www.kaggle.com/datasets/henrysue/online-shoppers-intention
(Online Shoppers Purchasing Intention Dataset — UCI ML Repository #468, mirrored on Kaggle.
12,330 sessions, 18 columns, no missing values, ~15.5% purchase rate.)

## How to run
1. `pip install pandas numpy scikit-learn matplotlib seaborn joblib kagglehub`
2. Open `MiniProject5_Purchase_Prediction.ipynb` and run all cells.
   - Cell 2 tries to download the real dataset from Kaggle via `kagglehub` first.
   - If Kaggle isn't reachable (no internet / no API token), it automatically falls back to
     `generate_dataset.py`, which reproduces the same column names, dtypes, and approximate distributions,
     so every later step (EDA, modeling, tuning, feature importance) runs identically either way.
3. Outputs (charts, CSVs) are written to `outputs/`; the final trained pipeline to `models/`.

## What's inside the notebook
1. Data loading (Kaggle → fallback) and data-quality checks
2. EDA with business-meaning explanations for each chart
3. Preprocessing pipeline (`ColumnTransformer`: median/most-frequent imputation, scaling, one-hot encoding)
4. Baseline models — Logistic Regression, Decision Tree, Random Forest
5. Optimization metric selection (F1, justified)
6. Hyperparameter tuning via `GridSearchCV` (5-fold) for all three models, including `class_weight="balanced"`
7. Hyperparameter sensitivity analysis (validation curves for `n_estimators`, `max_depth`)
8. Optimized model evaluation, confusion matrix, ROC curve
9. Feature importance (coefficients / `feature_importances_`) with a top-10 chart
10. Classification threshold analysis
11. Purchase-likelihood categories (Low/Medium/High) with calibration check
12. Business recommendations
13. Final conclusion

See `Model_Comparison_Report.md` for the full write-up, `Feature_Importance_Report.md` and
`Business_Recommendations.md` for the business-facing deliverables, and `Decision_Log.md` for why each
schema/modeling choice was made.
