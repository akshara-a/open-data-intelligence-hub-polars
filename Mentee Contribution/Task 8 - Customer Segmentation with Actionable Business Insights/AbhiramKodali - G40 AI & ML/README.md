# Customer Segmentation with Actionable Business Insights

## Project Overview
This project performs customer segmentation using Machine Learning techniques. Customers are grouped based on their purchasing behavior, allowing businesses to target different customer groups with personalized marketing strategies.

## Dataset
Source:
- UCI Machine Learning Repository – Online Retail II Dataset
